## 📌 About SubnetX

SubnetX is a browser-based networking toolkit created to make **IPv4 networking easier to understand and practice**.

Instead of using separate websites for subnet calculations, binary conversion, port references, MAC address conversion, and networking tutorials, SubnetX brings these features together in one application.

The application combines:

* 🧮 Networking calculators
* 🔧 Practical networking utilities
* 🎯 Interactive networking practice
* 📚 Structured networking lessons
* 📊 Detailed calculation results
* 📱 Responsive interface
* 🌙 Modern dark-themed UI

Everything runs locally in the browser, so networking calculations do not require sending user input to a backend server.

# 🧠 How SubnetX Works

SubnetX performs networking calculations directly inside the browser using JavaScript.

For example, when a user enters:

```text
IP Address: 192.168.1.25
CIDR:       /24
```

SubnetX calculates:

```text
Network Address:   192.168.1.0
Broadcast Address: 192.168.1.255
Subnet Mask:       255.255.255.0
First Host:        192.168.1.1
Last Host:         192.168.1.254
Total Addresses:   256
Usable Hosts:      254
```

No external networking service is required for these calculations.

# 🔐 Privacy

SubnetX is designed around local browser processing.

## No Backend Required

Networking calculations are performed locally using JavaScript.

This means user-entered values such as:

```text
IP addresses
CIDR values
MAC addresses
```

do not need to be transmitted to a server for calculation.
